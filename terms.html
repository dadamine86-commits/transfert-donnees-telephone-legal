Les présentes conditions définissent les règles d’utilisation de l’application Transfert Données Téléphone. En utilisant l’application, l’utilisateur accepte ces conditions.

1. Objet de l’application

Transfert Données Téléphone est une application Android destinée à faciliter la migration de données accessibles entre deux appareils Android appartenant à l’utilisateur.

L’application peut proposer le transfert de certaines catégories de données, selon les permissions accordées, la version Android, les restrictions du système et les modules disponibles.

2. Utilisation autorisée

L’utilisateur s’engage à utiliser l’application uniquement pour transférer ses propres données ou des données pour lesquelles il dispose d’une autorisation légitime.

L’application ne doit pas être utilisée pour accéder, copier, transférer ou conserver des données appartenant à une autre personne sans son consentement.

3. Données accessibles uniquement

L’application ne peut transférer que les données accessibles par Android et autorisées par l’utilisateur. Certaines données peuvent être limitées, incomplètes ou impossibles à transférer selon :

  • la version Android ;
  • le modèle du téléphone ;
  • les règles du constructeur ;
  • les permissions accordées ;
  • les restrictions de Google Play ;
  • le format ou l’état des données.

4. Absence de garantie de transfert complet

L’application vise à faciliter la migration de données, mais ne garantit pas que toutes les données seront transférées dans tous les cas.

Certains fichiers, messages, événements, contacts, historiques ou métadonnées peuvent ne pas être transférés si Android ou l’appareil ne l’autorise pas.

Avant toute migration importante, il est recommandé à l’utilisateur de conserver une sauvegarde indépendante de ses données.

5. Responsabilité de l’utilisateur

L’utilisateur est responsable de la vérification des données transférées sur le nouvel appareil. Il doit s’assurer que les informations importantes ont bien été récupérées avant de supprimer, réinitialiser ou revendre son ancien téléphone.

Neova Labs / SASU AMINE TELECOM ne peut pas être tenu responsable d’une perte de données causée par une mauvaise manipulation, une interruption de transfert, une restriction Android, un défaut matériel, une suppression manuelle ou une absence de sauvegarde indépendante.

6. Permissions Android

Certaines fonctionnalités nécessitent des permissions Android spécifiques. L’utilisateur peut accepter ou refuser ces permissions.

Si une permission est refusée, le module concerné peut être désactivé, limité ou ignoré pendant le transfert.

7. SMS et journal d’appels

Android peut imposer des conditions particulières, notamment un rôle temporaire d’application SMS par défaut ou d’application Téléphone par défaut pour certaines opérations de restauration.

L’utilisateur doit lire les explications affichées dans l’application avant d’accorder ces permissions ou rôles.

Les publicités peuvent apparaître sur des écrans non sensibles, par exemple l’accueil, les réglages ou certains écrans de rapport après la fin complète d’un transfert.
