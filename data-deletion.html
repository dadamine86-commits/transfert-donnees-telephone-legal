Cette page explique comment supprimer les données liées à l’utilisation de l’application Transfert Données Téléphone.

1. Principe général

Transfert Données Téléphone est conçue pour transférer des données localement entre deux appareils Android. L’application n’a pas pour objectif de créer un compte utilisateur, de stocker les données transférées sur un serveur ou de conserver une copie distante des données personnelles.

Les données transférées restent sur les appareils de l’utilisateur.

2. Suppression des données transférées

Les données importées sur le nouvel appareil doivent être supprimées depuis les applications Android concernées.

  • Contacts : depuis l’application Contacts ou les paramètres du compte utilisé ;
  • Calendrier : depuis l’application Calendrier utilisée sur l’appareil ;
  • Photos et vidéos : depuis la galerie ou le gestionnaire de fichiers ;
  • Documents : depuis le dossier de téléchargement ou le gestionnaire de fichiers ;
  • Musique / audio : depuis l’application Musique ou le gestionnaire de fichiers ;
  • SMS : depuis l’application Messages si les SMS ont été restaurés ;
  • Historique d’appels : depuis l’application si l’historique est affiché localement dans Transfert Données Téléphone.

3. Suppression des données locales de l’application

Si l’application conserve des données temporaires, des rapports ou certaines données locales, l’utilisateur peut les supprimer depuis les paramètres Android de son appareil.

Procédure générale :

  • Ouvrir les paramètres Android ;
  • Aller dans Applications ;
  • Sélectionner Transfert Données Téléphone ;
  • Ouvrir Stockage ;
  • Choisir Effacer les données ou Vider le cache.

Effacer les données de l’application peut supprimer les réglages locaux, les rapports de transfert ou certaines informations conservées localement dans l’application.

4. Absence de compte utilisateur

L’application ne nécessite pas de compte utilisateur pour effectuer un transfert local. Il n’y a donc pas de compte à supprimer auprès de Neova Labs / SASU AMINE TELECOM.

5. Données publicitaires

L’application peut utiliser Google AdMob pour afficher des publicités. Les données publicitaires éventuelles sont traitées selon les règles de Google et les choix de consentement de l’utilisateur.

L’utilisateur peut gérer ou réinitialiser son identifiant publicitaire depuis les paramètres Android de son appareil, selon la version Android utilisée.
