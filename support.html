Cette page permet aux utilisateurs de contacter le support pour l’application Transfert Données Téléphone et de comprendre les principales limites liées au transfert de données Android.

1. Contacter le support

Pour toute question, problème technique, demande liée à la confidentialité ou signalement concernant l’application, vous pouvez nous contacter par e-mail :

E-mail : dadamine86@gmail.com

Pour faciliter le traitement de votre demande, merci d’indiquer si possible :

  • le nom de l’application : Transfert Données Téléphone ;
  • le modèle de votre ancien téléphone ;
  • le modèle de votre nouveau téléphone ;
  • la version Android des deux appareils ;
  • la catégorie de données concernée : contacts, photos, vidéos, fichiers, musique, calendrier, SMS ou appels ;
  • une description claire du problème rencontré.

2. Fonctionnement général de l’application

Transfert Données Téléphone est conçue pour transférer des données accessibles entre deux appareils Android. Le transfert repose sur un appairage entre les appareils, notamment par QR code, puis sur une communication locale.

Les données transférées ne sont pas destinées à être envoyées vers un serveur externe de Neova Labs ou de SASU AMINE TELECOM.

3. Données pouvant être transférées

Selon la version de l’application, les permissions accordées et les limites Android, l’application peut proposer le transfert de certaines catégories de données :

  • contacts ;
  • photos et vidéos sélectionnées ;
  • fichiers et documents sélectionnés ;
  • musique ou fichiers audio sélectionnés ;
  • événements de calendrier compatibles ;
  • SMS si le module est disponible et autorisé ;
  • historique d’appels si le module est disponible et autorisé.

4. Limites possibles

Certaines données peuvent ne pas être transférées ou restaurées complètement. Cela peut dépendre de plusieurs facteurs :

  • la version Android ;
  • les restrictions du fabricant du téléphone ;
  • les permissions refusées par l’utilisateur ;
  • les règles Google Play ;
  • les restrictions de sécurité Android ;
  • les fichiers protégés, endommagés ou inaccessibles ;
  • les données non compatibles avec le nouvel appareil.

Avant de réinitialiser ou vendre un ancien téléphone, vérifiez toujours que vos données importantes ont bien été transférées sur le nouvel appareil.

5. Permissions Android

L’application demande uniquement les permissions nécessaires aux modules utilisés. Si une permission est refusée, la catégorie concernée peut être ignorée ou limitée.

Par exemple :

  • la caméra peut être utilisée pour scanner un QR code ;
  • les contacts peuvent nécessiter une permission de lecture ou d’écriture ;
  • le calendrier peut nécessiter une permission de lecture ou d’écriture ;
  • les SMS ou le journal d’appels peuvent nécessiter des permissions sensibles si ces modules sont activés ;
  • les photos, vidéos, documents et fichiers audio peuvent être sélectionnés manuellement par l’utilisateur.

6. Publicités

L’application peut utiliser Google AdMob pour afficher des publicités. Les publicités ne doivent pas apparaître pendant les étapes sensibles comme le transfert en cours, l’appairage, les permissions, le scan QR ou la restauration de données sensibles.

Les publicités peuvent être affichées sur des écrans non sensibles, comme l’accueil, les réglages ou certains écrans de rapport après la fin complète du transfert.
