Transfert Données Téléphone est une application Android de migration de données entre téléphones. Elle permet de transférer des données accessibles entre deux appareils Android de manière locale et sécurisée.

Résumé confidentialité

Les données transférées par l’application ne sont pas envoyées vers un serveur de Neova Labs ou de SASU AMINE TELECOM. Les transferts sont conçus pour rester locaux entre les appareils de l’utilisateur.

L’application peut utiliser Google AdMob pour afficher des publicités sur certains écrans non sensibles. Aucune publicité ne doit être affichée pendant les étapes sensibles comme l’appairage, les permissions, le scan QR, le transfert en cours, la restauration des SMS ou les écrans liés au journal d’appels.

Données pouvant être concernées

Selon les modules disponibles, les permissions accordées et la version Android, l’application peut proposer le transfert ou le traitement local de certaines catégories de données :

  • contacts ;
  • calendrier ;
  • photos et vidéos sélectionnées ;
  • documents et fichiers sélectionnés ;
  • musique ou fichiers audio sélectionnés ;
  • SMS si le module est disponible et autorisé ;
  • journal d’appels si le module est disponible et autorisé.

Certaines données peuvent ne pas être transférées selon les restrictions Android, les permissions refusées, le modèle du téléphone, le constructeur ou les règles Google Play.
