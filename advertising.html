Cette page explique comment les publicités peuvent être utilisées dans l’application Transfert Données Téléphone et quelles règles sont prévues pour protéger les données transférées par l’utilisateur.

1. Utilisation de Google AdMob

L’application peut utiliser Google AdMob afin d’afficher des publicités sur certains écrans non sensibles. Les publicités permettent de soutenir le développement, la maintenance et l’amélioration de l’application.

Google AdMob peut traiter certaines données techniques nécessaires à l’affichage, à la mesure et à la personnalisation éventuelle des annonces, selon les choix de consentement de l’utilisateur et les règles applicables.

2. Consentement publicitaire

Lorsque cela est nécessaire, notamment dans l’Espace économique européen, au Royaume-Uni et en Suisse, l’application peut utiliser le système Google UMP afin de recueillir les choix de consentement de l’utilisateur avant l’affichage de publicités personnalisées ou non personnalisées.

L’utilisateur peut être invité à choisir ses préférences concernant l’utilisation de ses données publicitaires. Ces préférences peuvent concerner notamment les annonces personnalisées, les annonces non personnalisées ou certains traitements publicitaires réalisés par Google et ses partenaires.

3. Données transférées non utilisées pour la publicité

Les données transférées par l’utilisateur dans l’application ne sont pas transmises à AdMob par notre code et ne sont pas utilisées par Neova Labs / SASU AMINE TELECOM pour cibler les publicités.

Cette règle concerne notamment :

  • les contacts ;
  • les SMS ;
  • le journal d’appels ;
  • les événements de calendrier ;
  • les photos et vidéos sélectionnées ;
  • les fichiers et documents sélectionnés ;
  • les fichiers audio ou musique sélectionnés.

4. Séparation entre publicité et transfert

L’application est conçue pour séparer les fonctionnalités de transfert de données et les fonctionnalités publicitaires.

Les modules de transfert ne doivent pas transmettre le contenu des données personnelles à AdMob. Les publicités ne doivent pas être déclenchées à partir du contenu des SMS, du journal d’appels, des contacts, du calendrier ou des fichiers transférés.

5. Écrans où les publicités peuvent apparaître

Les publicités peuvent apparaître uniquement sur des écrans non sensibles, par exemple :

  • l’écran d’accueil ;
  • certains écrans de réglages ;
  • certains écrans d’information ;
  • certains écrans de rapport après la fin complète d’un transfert.

6. Écrans où les publicités ne doivent pas apparaître

Par conception, aucune publicité ne doit être affichée pendant les étapes sensibles suivantes :

  • génération ou scan du QR code ;
  • appairage entre les appareils ;
  • demande de permissions Android ;
  • connexion entre les appareils ;
  • transfert de données en cours ;
  • restauration des données sur le nouvel appareil ;
  • écrans liés aux SMS ;
  • écrans liés au journal d’appels ;
  • écrans liés au changement temporaire d’application SMS ou Téléphone par défaut ;
  • écrans expliquant l’utilisation de permissions sensibles.

L’utilisateur ne doit jamais être obligé de regarder une publicité pour terminer un transfert déjà commencé ou pour récupérer ses propres données.

7. Identifiant publicitaire

Si les publicités sont activées, Android et Google AdMob peuvent utiliser l’identifiant publicitaire de l’appareil selon les règles applicables et les préférences de consentement de l’utilisateur.

L’identifiant publicitaire n’est pas utilisé par Neova Labs / SASU AMINE TELECOM pour accéder au contenu des données transférées.

8. Gestion des choix de l’utilisateur

Selon la région et la configuration de l’application, l’utilisateur peut avoir accès à un écran de gestion du consentement publicitaire.

L’utilisateur peut également gérer certaines préférences publicitaires directement depuis les paramètres Android ou les paramètres de son compte Google.

9. app-ads.txt

L’application utilise un fichier app-ads.txt afin d’indiquer les vendeurs autorisés pour les annonces diffusées dans l’application.
